# قط متكلم (Talking Cat)

تطبيق أندرويد لتعليم الحروف العربية للأطفال (التعلّم، الدروس، الألعاب).

## البناء على GitHub
1. ارفع محتويات هذا المجلد إلى مستودعك.
2. من تبويب **Actions** شغّل **Build APK** (Run workflow). يمكنك تغيير الأصوات المضمّنة (الافتراضي `9,1,3,6,7`).
3. يعمل البناء على مرحلتين:
   - **pregen**: كل صوت يُولَّد ويُتحقَّق من نطقه على جهاز مستقل وبالتوازي، وكل جهاز يستخدم كل أنوية المعالج.
   - **build**: يجمع الأصوات الجاهزة ويبني التطبيق (بدون أي توليد إضافي).
4. نزّل `talking-cat-apk` من Artifacts. وفي `pack-report-v*` تقرير بالعناصر التي لم يجتز نطقها التحقق.

إن انتهى وقت التوليد قبل اكتمال صوت ما، يُحفظ ما تم في الكاش ويُكمَّل في التشغيل التالي، والباقي يُولَّد على الجهاز.
التفاصيل في [BUILD.md](BUILD.md).
