# قط متكلم (Talking Cat)

تطبيق أندرويد لتعليم الحروف العربية للأطفال (التعلّم، الدروس، الألعاب).

## البناء على GitHub
1. ارفع محتويات هذا المجلد إلى مستودعك.
2. من تبويب **Actions** شغّل **Build APK** (Run workflow).
3. أثناء البناء يُنزَّل محرك sherpa-onnx ونماذج الصوت وتُولَّد الأصوات الجاهزة ويُتحقَّق منها تلقائيًا (`fetch-engine.sh` و`tools/pregen.py`)، لذلك هذه الملفات غير موجودة في المستودع.
4. بعد انتهاء البناء نزّل `talking-cat-apk` من Artifacts.

التفاصيل الكاملة في [BUILD.md](BUILD.md).
